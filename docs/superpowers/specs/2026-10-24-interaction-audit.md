# Qt 交互审计与媒体浏览

本轮基于已获授权的手动创作界面，检查全部已有入口并修正行为。参考用户当前登录的 Pixo 媒体页的实际可见交互：紧凑导航、卡片集合、分组筛选、选中状态、预览弹层、前后切换、信息侧栏、项目菜单、操作反馈。

保留自己的 3D 工作台、七步流程、MVC 和 OpenGL 封装。AI 对话、收费、社区、分享、音视频时间线没有当前业务，不增加无效入口。Pixo 的图片筛选在本次实测返回 0 项，即使全部中有图片；这一行为不复制。

必须修正：相机复位与预设一致；编辑单个字段不量化其他值；已有路径直接保存，另存为独立入口；打开工程先处理未保存修改；无选中/达到灯光上限时禁用对应动作；空集合与搜索无结果分别反馈；焦点、悬停、按下、选中、禁用状态明确。

媒体模块：镜头与导出共用 MediaGallery；搜索、场景/状态筛选、计数、卡片、预览、前后切换、详情开关。镜头支持恢复、重命名、移除；导出支持打开文件、打开目录、移除记录。删除记录不删除磁盘作品。快照与记录仍仅本次会话保留，界面明确说明。

约束：Qt cpp ≤320 行、头文件 ≤260 行、测试 cpp ≤420 行。图库不能依赖渲染器；业务动作仍交给 WorkbenchWindow → Controller。检查使用真实 OpenGL 上下文，测试只对测试应用关闭原生系统对话框。
