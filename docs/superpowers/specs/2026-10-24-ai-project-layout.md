# AI 创作项目的整体布局

依据：用户要求整体参考 Pixo；已在登录态实际查看首页、项目故事版、媒体、时间线。只观察参考项目，不提交生成任务或修改内容。

首页以创作输入为中心，提供文本规划、附图分析、场景起点和继续当前工程。提交新想法先执行现有未保存保护，再创建工程并通过同一个 ChatPanel/AIService 提交。模型服务设置只有顶栏一个入口，默认明确标注本地演示。

项目页采用顶栏视图导航，左侧 AI 助手常驻，右侧依次提供方案、3D 场景、镜头、媒体、时间线。切换视图保留同一对话、任务、素材和时间线。方案生成后自动显示方案；人工确认成功后自动显示时间线。助手可以隐藏和恢复，不取消任务。

StudioWorkspace 成为项目容器，拥有 StudioDocument、对话以及项目视图栈。WorkbenchWindow 组合首页和项目容器、工程动作、OpenGL 编辑页面。ChatPanel 不再承担整个软件的页面导航。删除独立编排页和旧侧栏，不保留兼容空页面。

3D 场景的对象与属性使用同一个右侧面板的两个标签，避免助手加进来后挤出视口。媒体页分别呈现持久化项目素材与会话导出记录；从素材定位到时间线中的片段。时间线保留真实本地视频播放、裁剪、拆分、重排、图片片段。

沿用第一、第二阶段的全部渲染功能、自有 OpenGL 封装、OpenAPI 3.1.1、人工确认和中文文案。本轮不实现 Go 服务或真实模型供应商，不复制付费、社区和未实现的生成入口。

硬约束：Qt 实现文件最多 320 行，头文件最多 260 行，原生测试最多 420 行；不压缩排版规避。最低窗口 1100×720，常用按钮和主内容可访问，长内容滚动。所有文档和博客只交付中文版。

验收：默认首页可输入创作；跨项目视图对话常驻且实例不变；生成→审阅→确认→时间线连通；素材和时间线共享资产；设置窗口不泄漏令牌；助手隐藏恢复保持任务；1100×720 不被最小尺寸撑大；现有渲染、工程与交互回归通过；实际截图和运行最新程序。
