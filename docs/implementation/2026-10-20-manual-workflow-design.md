# Qt 人工创作流水线与界面改版

本轮落实用户已授权的 Qt 美观、布局与交互改版，参考 Pixo 已实际查看的首页、项目卡片、素材分组、故事版和任务抽屉。以当前第一阶段渲染能力提供真实闭环，不复制网站的付费、社区发布与视频生成业务。

## 产品结构

- 窄侧栏：创作首页、工作台、镜头快照、导出记录；底部操作帮助。
- 首页：中文标题、继续创作、新建场景模板卡片、打开本地工程。模板来自真实预设，不伪装 PBR 或 Toon 已实现。
- 工作台：顶部工程名与保存、五阶段导航；左侧场景与搜索；中间真实 QtViewport 与轻量工具栏；右侧按阶段呈现场景变换、材质、镜头、渲染检查和导出。
- 镜头快照：保存真实视口缩略图和相机姿态，可恢复镜头；这是静帧镜头集合，不是视频时间线。
- 导出：保存 PNG 到指定位置，成功后进入可打开的记录；错误保留、可以重新执行。
- 工程文件：版本化 JSON，包含模板、TRS、材质值与共享关系、相机、渲染设置；先完整校验，再加载。当前不提供任意模型、纹理导入。

## 模块与边界

`WorkflowState` 属于不依赖 Qt/GL 的 CPU 层，管理阶段完成与下游失效。`ProjectDocument` 负责 Qt JSON 读写与经过 Controller 的恢复。`WorkbenchTheme` 负责配色与通用界面组件。`WorkbenchWindow` 组合页面并协调交互，`WorkbenchStages` 构建步骤面板，`WorkbenchPages` 构建首页与集合页，`WorkbenchActions` 处理文件和快照操作，`QtUiHelpers` 复用控件创建。QtViewport 继续独占上下文生命周期，Renderer 与 NativeResourceFactory 不改变职责。

当前执行者是人。以后自动执行器应调用相同的 EditorController 操作与工作流失效规则；本轮不加入网络、AI SDK、假生成进度或空执行器框架。

## 验收

1. 原 Qt 集成验证仍可操作预设、对象、位置、相机和 PNG。
2. CPU 测试证明修改上游使下游完成状态失效。
3. Qt 集成验证页面切换、搜索、步骤导航、镜头捕获恢复、工程保存加载、损坏工程拒绝、导出错误。
4. 实际截图检查 1440×900 与 1100×720，无横向溢出与主要按钮遮挡。
5. 新增中文文章和更新运行说明，清楚区分当前能力与后续课程。
