- 三个预设 × 四种风格的 12 个组合均能切换，状态文字与按钮同步。
- 已检查机器人二次元、写实、霓虹、线框，以及材质展台和庭院的实际渲染截图。

- `index.html` 已内嵌脚本、着色器和程序生成的网格，无外部 script src 或模型/图片请求。

## 修复过的回归

1. 地面和球体三角形绕序与法线相反，导致背面剔除后不可见或呈内翻效果。修正索引，并用 `geometry.test.cjs` 验证立方体、平面、球、封顶圆柱、圆环的非退化三角形朝向。
2. `[data-scene]` 及 `[data-style]` 的按钮查询同时匹配诊断属性所在的 canvas，导致画布点击隐式重建场景并重置相机。将查询限定为 `.preset[data-scene]` 与 `.style-button[data-style]`。修复后拖动可改变相机，同时轨道伙伴保留绿色主题。
3. 霓虹模式地面在掠射角产生大范围轮廓光，Bloom 后过曝。对环境/地面单独控制发光贡献，保持主体轮廓光。

## 工具验证限制

浏览器自动审批禁止工具访问 file://，仅允许 HTTP/HTTPS，因此直接双击打开的协议路径没有被自动浏览器实测。验证使用同一份离线 HTML 的本地 HTTP 预览；单文件完整性和 JavaScript 语法由命令行检查。

鼠标右键平移、Q/E 和所有滑杆的边界值可作为后续扩展时的手动复查项；未把这些未逐一执行的动作标为已验证。
